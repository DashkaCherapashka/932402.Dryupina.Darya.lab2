## Описание

Оформление страницы «О себе» из ЛР1 с помощью внешнего CSS-файла `style.css`.
Реализованы переменные, позиционирование, состояния, псевдоэлементы и анимации.

## Что реализовано

### Три способа подключения стилей
- Внешний файл — `style.css`
- Внутренний `<style>` — правила для списка навыков
- Inline-стили — на `<img>` и `<form>`

### CSS-переменные (`:root`)
- `--color-primary: #531a5e` — тёмно-фиолетовый
- `--color-accent: #c33aed` — ярко-фиолетовый
- `--font-heading: 'Yeseva One'`
- `--font-body: 'Montserrat'`

### Позиционирование
- `position: static` — у `<footer>`
- `position: relative` — у `<header>`, `<section>`, `<aside>`, `<form>`
- `position: absolute` — у псевдоэлементов `::before` и `::after`

### Состояния элементов
- `:hover` — карточки, ссылки, теги, кнопка
- `:active` — кнопка формы, ссылки в aside
- `:focus` — поля формы, кнопка, ссылки
- `:visited` — ссылки на Яндекс Музыку и Spotify

### Визуальные волны (задание варианта 9)
- Псевдоэлементы `::before` и `::after` создают «звуковые волны»
- При `:hover` волны увеличиваются и меняют цвет

### Дополнительно
- Пульсирующая рамка вокруг аватара (`@keyframes pulseGlow`)
- Эквалайзер из 15 анимированных столбиков
- Плавное появление элементов при загрузке (`@keyframes fadeInUp`)
- Ссылки на Яндекс Музыку и Spotify в боковой панели
